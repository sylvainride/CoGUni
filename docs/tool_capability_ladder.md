# Capability observations

Track each capability as declared, callable, tested, connected and authorized,
with source/session/version, scope, expiry and cost observation. These are
separate facts. A listed callable does not prove installation, successful use,
live permission or a production broker connection.

The pure router has only synthetic capability inputs. FAKE_API, FAKE_CLI and
SIMULATED_BROWSER name plans, not installed executors. No permitted route yields
DENY; a disabled planner yields DISABLED. A future runtime adapter must report
BLOCKED_TOOL for missing callable support, BLOCKED_PERMISSION for absent scope,
and recheck live owner grants before execution. It cannot interpret a simulated
budget or a route choice as authorization.
